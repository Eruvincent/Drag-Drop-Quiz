🤖 Prompt para sa AI (ChatGPT / Gemini / Claude)

Kopyahin ang prompt na ito at i-paste sa ChatGPT o Gemini upang gumawa agad ng JSON file ng iyong mga tanong:

Gumawa ka ng valid JSON array para sa isang quiz. Ang bawat item ay dapat may "id" (number), "question" (string), "options" (array ng 3 o 4 na pagpipilian), at "answer" (string na eksaktong kapareho ng isa sa mga pagpipilian). Sagutin lamang ako gamit ang JSON codeblock nang walang ibang karagdagang text. Paksa: [ILAGAY ANG PAKSA DITO]

Halimbawa ng JSON Format Structure

[
  {
    "id": 1,
    "question": "Ano ang pambansang ibon ng Pilipinas?",
    "options": ["Maya", "Agila", "Kalaw"],
    "answer": "Agila"
  },
  {
    "id": 2,
    "question": "Sino ang pambansang bayani ng Pilipinas?",
    "options": ["Andres Bonifacio", "Jose Rizal", "Emilio Aguinaldo"],
    "answer": "Jose Rizal"
  }
]
